# 006 — Continuous integration

## Goal

Run the same quality gates as `CLAUDE.md` on every pull request, including the PostgreSQL
tests that are skipped on a machine without a database.

## Scope

- `.github/workflows/ci.yml`: Python 3.12, PostgreSQL 16 as a service container,
  `ruff check`, `ruff format --check` and `pytest` (coverage gate 90 %).
- Least privilege: `permissions: contents: read`; no secrets are needed because no test calls
  a real LLM provider.
- `concurrency`: a new push cancels the previous run of the same branch.
- Guard test: when `CI` is set, `TEST_DATABASE_URL` must be set too, so the database tests can
  never be skipped silently in CI.
- `.github/dependabot.yml`: weekly update PRs for GitHub Actions and pip dependencies.

## Notes

- Provider comparison (`scripts/compare_wording.py`) is deliberately not part of CI: it calls
  paid APIs and needs keys.
- Action versions are pinned to a major tag (`checkout@v7`, `setup-python@v6`); Dependabot keeps
  them current. Pinning to commit SHAs is the stricter option if the project ever needs it.
- Branch protection (require the `test` check before merging) is a repository setting, not code.
